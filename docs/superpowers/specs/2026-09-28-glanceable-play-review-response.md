## 用户决策

| 议题 | 决定 |
|---|---|
| 评分 | 星级只看提示；取消「安排好啦」，改为自动过关 |
| 故事 | 顶部常驻一句话，点开看完整故事 |
| 心愿 | 候场卡显示图标，点开后是气泡 |
| 推理乐趣防护 | 接受 5 条防护（包括爪印） |
| 防试错 | 爪印可见，条件改为「从未出现 !」 |
| 删冗余规则 | 本轮只出报告 |
| 星级区分度下降 | 接受，由爪印承担区分度 |
