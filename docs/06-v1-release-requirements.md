# 给喵挪个位 v1.0 · 最终首发需求基线

版本：1.0-draft.1；日期：2026-09-15。状态：开发范围基线，功能尚未实现。

依据：用户要求直接按最终上线版本整理需求、拆分任务和开发方式。本文覆盖正式版目标；01—04为原型历史记录，05为规划背景。如有冲突，正式版以本文和07—09为准。产品变更通过本文版本记录，不在任务实施中悄悄增减范围。

## 1. 首发范围与计数口径

| 项目 | 首发交付 |
|---|---|
| 平台 | 微信小游戏；浏览器作为共享代码的开发预览，不宣称为另一正式发行渠道 |
| 主线 | 90关，3章各30关 |
| 每日挑战 | 14道独立谜题，按14日周期轮换，第2轮标注“经典回顾” |
| 更新储备 | 20道已验收关卡，不在首发客户端发布清单中暴露 |
| 关卡总产量 | 124道；现有30道经过质量评审后复用，需新增至少94道 |

## 2. 玩家路径

首次进入：启动/必要提示 → 首页 → 第1关 → 渐进引导 → 结算 → 下一关。前5关不要求账号资料、云同步或广告。平台规定的必要流程根据账号实际要求接入，不用自制弹窗冒充完成官方要求。

回访：恢复本地存档 → 首页继续上次未完成关；已有完成局面时继续下一未完成可进入关。显示每日挑战（主线完成5个不同关卡后解锁）、章节进度和纪念册新卡提示。

卡关：免费读规则与冲突 → 免费线索高亮 → 主动请求高级提示 → 可用免费权益/自愿广告 → 给出一步有理由的建议 → 玩家手动操作。不得自动替玩家通关。

主线全通关：保留重玩、每日题和纪念册入口，展示已开放内容全部完成。不把未制作的关卡显示为可玩的“下一关”。

## 3. 功能需求与验收

### F01 排座核心
- 选人查看、点空位入座、显式移动后点占用位交换、拖动交换、退回、撤销、重置。
- 没有计时、生命、体力和错误惩罚；重置需防误触确认，仍可撤销。
- 成功由所有人已入座且全部条件满足判断；多解一律允许。
- 触摸取消、来电/切后台、调整窗口不提交半次移动。
- 验收：所有发布关的参考解通过；替代解、错误解、异常操作、末关边界有测试。

### F02 教学与规则说明
- 主线1—5分别引导选人、放座位、查看冲突、换位/撤销、关系与空位。
- 引导以完成真实动作推进；退出恢复当前步骤；已完成引导不强制重播。
- 6种约束在首次出现时解释，可在设置重看。
- 验收：不靠口头指导的20—30人可用性观察；记录误解，修复后重测。

### F03 提示
- L1：条件解释、关系对象和环境区域高亮，始终免费。
- L2：指出当前布局的一步可行操作＋一条理由。不能显示无法推导的“准确答案”而无解释。
- 每个主线/日题首次游玩提供1次免费L2，领取/消费状态持久化；重开、刷新和重玩不刷新额度。
- 主线1—10为教学保护区，L2不受额度限制，无广告入口。第11关起以及每日挑战可提供自愿广告（需完成前10关才展示该入口）。
- 默认每局最多3次已完成广告、间隔至少90秒；均为首发产品默认值，不是平台限制。更保守的平台限制优先；配置只允许降低、关闭，不远程提升强度。
- 无广告填充/加载失败：每个关卡版本额外允许1次免费L2救济，持久化去重；用户取消播放不消耗免费权益也不伪造发奖。
- 提示权益与levelId绑定，已获权益不因退出或暂时切换关卡丢失。
- 验收：多错误分步修复、提示循环检测、切后台/换关/重复回调、权益扣除与布局变化均覆盖。

### F04 主线
- 主线顺序清单控制展示与下一关，不做ID算术。
- 新玩家章节依次开放，前章30关完成后开放下一章；章内按前置关解锁。
- 任何已完成关可重玩，老demo迁移得到的章节访问资格保留。
- 展示已完成/可进入/锁定三态，章节结算和总通关不同。
- 验收：90关连续流程、新老存档、插入关、末关和存档恢复均通过。

### F05 每日挑战
- 完成5个不同主线后开放。14题独立于主线，ID独立。
- 时区固定Asia/Shanghai，00:00切题；以发布时在构建清单写入的cycleAnchorDay计算，版本升级不自动重置。
- 有服务端时间时校准；离线使用已记录日期与设备日期，检测日期回退时不回退已领取状态。无排行/交易价值，首发不宣称防改时作弊。
- 跨零点进行中的局继续旧题，完成后显示已跨日；旧日结果记旧日，玩家手动进入新题。
- 每轮重复题明确标注经典回顾；可重玩过去已缓存题但不再次发同一日期奖励。
- 验收：23:59→00:01、首次离线、断网、设备日期倒退、14/15日轮换和跨日存档。

### F06 纪念册
- 12张卡按不同主线完成数量解锁：5、10、15、20、30、40、50、60、70、80、85、90。
- 同卡只能领取一次，已解锁未领取有提示；云合并不重复播放领取/重复奖励。
- 每日题和储备关不计主线里程碑，卡片没有虚拟货币或商品价值。
- 验收：重复过关、重玩、迁移、云合并、离线领取再同步均正确。

### F07 设置与声音
- 音乐、音效、震动独立开关；减少动效选项；保存设备设置。
- 音频初始化失败静音继续，不阻塞场景。切后台暂停，回前台遵循用户设置。
- 3段合法可商用循环音乐、约10种音效、8组交互动画。减少动效时保留静态反馈。
- 验收：首次交互、后台/前台、静音恢复、资源失败、低性能设备。

### F08 进度
- 每次有效动作保存本地；最新完整存档与上一有效快照分开，格式校验后提交。
- 兼容当前version:1存档；先备份再迁移，失败仍可读原存档，不偷偷清空。
- 提供云备份功能，由用户按实际数据处理流程开启；未开启/拒绝不影响本地游戏。
- 完成集合合并；当前布局按内容版本和会话标识处理，冲突提供保留本机/恢复云端选择，不混排人物。
- 云保存采用修订号比较，客户端重试幂等；服务失败保留待同步状态。
- 清理本机数据与删除云数据区分；云删除完成后防止待上传队列重新创建记录。
- 验收：升级/降级保护、损坏/满存储、两设备离线冲突、身份变化、删除后同步。

### F09 广告
- 首发只有rewarded hint入口，无横幅、强制插屏、强制分享。
- 真实SDK隔离在微信适配层；浏览器标识“开发预览”，不记录模拟展示为真实收入。
- loading/showing/earned/cancelled/unavailable/error明确状态，同一时刻只允许一场广告。
- 发奖绑定不可复用requestId和原levelId，仅完整观看发一次；晚到回调不奖励新关卡。
- 未配置广告位/能力未获准时入口隐藏；需接入实际平台并取得失败与完成场景证据才算联调完成。

### F10 监控
- 事件字典、版本、去重、采样、脱敏和实际数据同意流程完整；不上传逐次原始答案、手机号、照片或通讯录。
- 初始事件15种：app_open、tutorial_complete、level_start、level_exit、level_complete、hint_request、hint_granted、ad_request、ad_show、ad_complete、ad_cancel、ad_error、daily_complete、storage_error、runtime_error。
- sessionId、eventId、匿名安装标识只在所需同意后创建/传输；事件levelId为稳定ID，额外带buildId/contentVersion。
- 广告净收益来自实际结算/平台报表，可手工汇入；不能从ad_complete自行编造收益。
- 数据表保留默认：原始玩法事件30日、无身份聚合90日；错误日志14日。删除策略落实后验收，最终告知文案匹配实际行为。
- 验收：未同意不上报、重复事件去重、错误离线上限、测试环境不污染生产数据。

### F11 内容工具
- 本地可视化座位/人物/规则编辑，运行真实引擎预览；不是仅能手改JS。
- 校验ID、规则引用、布局、标签、可解性、多解和提示路径；提供人工设计意图/难度记录。
- 导出版本化数据与资产引用；临时编辑不影响运行游戏文件，明确导出/导入。
- 储备内容和作者参考解只保存在作者目录，不进入生产客户端。

### F12 运营配置
- 内置安全默认值、配置schemaVersion、有效期、缓存及失败回退。
- 仅允许广告关闭/降低频次、遥测采样、已发布关卡暂停等白名单；不能动态执行代码或开放未审查内容。
- 关卡被暂停时给出正常返回和重玩出口，云修订号与配置版本分离。
- 运营使用版本化配置＋简单报表，无首发复杂管理后台。

### F13 服务与隐私
- 设置内可查看隐私、数据用途、反馈/投诉、删除数据入口。
- 素材授权记录、工作名查重、实际运营主体和客服信息真实可用。
- 所需年龄/实名认证/健康提示等按实际平台准入核验并接入，不能用假身份或虚构审批号填充。
- 不索取或提交密码、AppSecret和付款资料到客户端或文档。

### F14 平台发布
- 微信工具、至少2台iOS和3台Android实机（含目标低性能设备），逐项记录机型/系统/基础库/网络/版本。
- 正确处理安全区、胶囊、音频、后台、弱网与资源错误；核心离线内容可启动。
- 发行构建与开发构建分离，不含编辑器、reference、测试标识、储备题、秘密或调试入口。
- 构建包含清单和哈希，产物可追溯；代码回退通过平台允许的版本流程，不能用配置切换远程代码。
- 平台资格清单与证据保存在发布记录；账号未核验不得标“可上线”。

## 4. UI与内容硬性质量

- 主线难度总量：轻松36、普通40、挑战14；这是作者目标，盲测后重新归类。
- 新手5关目标15—60秒，普通1—3分钟，挑战3—5分钟；记录中位数，不与平台指标混用。
- 实际可用屏幕320—430 CSS px宽（扣安全区）重新布局；正文14—16、辅助≥12，触控≥44×44、主要按钮≥48高。
- 不通过整画布缩小达标；短屏可以折叠需求卡和滚动候场，必须能访问全部人和完整条件。
- 角色12个有轮廓差异；场景3套×4变体；功能物件约24；UI图标约22；纪念卡12；推广展示图5、视频3。
- 场景标签与逻辑范围完全一致；窗口/音箱等不可仅装饰却误导玩家。
- 每道题通过自动可解检查和人工手机检查；有解不等于有趣，作者必须写一条独立推理点。
- 60fps为拖动目标；约定低性能设备不持续低于30fps；中端冷启动P95目标≤5秒。具体设备和网络写进报告，没有实测不算达标。

## 5. 不包含

第4场景、120关公开主线、真人社交、排行榜、商城支付、抽卡、交易、体力、经营养成、玩家出题、永久每日新题承诺。

## 6. 交付与发布状态

代码完成：实现＋测试＋自审；功能联调完成：真实环境可复现证据；内容完成：自动检查＋人工验收＋素材权利记录；发布通过：全部P0缺陷关闭、准入材料通过、真机与生产服务可用。

留存/收入实验用于经营判断，不作为编造上线资格的依据。不因排期将未登录工具、未开通广告或假服务标为完成。
