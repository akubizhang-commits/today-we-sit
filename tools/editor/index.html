相邻关系

相邻关系是双向的，座位不会自动成为邻座。点击下方连线可将其移除。

试坐与验证

选择小动物后，在“试坐预览”模式点击座位；已入座小动物可交换位置。“求解”会重新安排全部小动物，仅影响预览。达到搜索上限时，不能据此判断关卡无解。

导入与导出 JSON

每次导入一个独立关卡，最多 8 位小动物、12 个座位。校验通过后替换草稿，移除导入的参考答案，不修改项目源文件。

草稿导出只校验数据结构，不保证有解。只有“求解并下载作者 JSON”会计算并加入参考答案。规则始终由你逐条设置。
