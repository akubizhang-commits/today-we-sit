原创排座解谜微信小游戏原型。3 个场景、30 个关卡；点选/拖放安排人物，让所有偏好同时满足。原生 Canvas 2D，浏览器和微信共用逻辑与画面，零第三方运行时依赖。

## 浏览器试玩

Node.js 20 或更高版本，无需 `npm install`：

```sh
cd /Users/zhangnu/WeChatProjects/today-we-sit
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。服务只监听本机。端口被占用时：

```sh
SEAT_GAME_PORT=4174 npm run dev
```

修改源码后重新执行 `npm run build` 并刷新网页即可；当前没有热更新。若预览服务还在运行，不需要重启它。

## 怎么玩

- 点候场人物，再点空座位；或直接拖动人物入座。
- 点已经就座的人查看偏好。点“换个位置”后，再点另一人物交换；拖动到另一个人也可交换。
- 选中人物后点候场区空白处，可让其暂时离席。
- 对勾表示满足，感叹号表示冲突，圆点表示还需等待其他人物入座。
- 相邻只算同排左右紧挨着，不跨行。座位下面显示编号和环境标签。
- 免费撤销、重新安排和提示。提示文字可点击关闭，不会点到后面的人物。
- 每次操作自动本地保存，刷新后从首页继续。清理浏览器/微信本地数据会丢失进度。

## 商业化状态

提示目前完全免费。真实广告位、支付、后端、远程统计都没有启用。`action('hint')` 是广告接入位置；此原型不伪造广告播放或收益。仅记录最近最多100条本地玩法事件，不上传。

正式上线还需要自己的主体/AppID、平台要求的备案和相关资质、隐私说明、真机测试，以及按所需广告/支付功能核验资格。工作名也需要发布前查重。

## 已知产品限制

- 没有音乐音效、角色对话动画、每日挑战和云同步。
- 当前30关是功能验证内容，尚未进行真实用户难度和留存测试。
- 短屏采用等比缩放；小屏下文字可能偏小，正式版仍需针对目标真机调整。
- Canvas 暂不支持完整键盘或屏幕阅读器操作。
- 本地存档用于体验，不提供防作弊保证。

代码与关卡独立编写，不包含 Is This Seat Taken? 的素材、角色、文本或关卡。
